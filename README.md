# Аномалия-5

Атмосферный 3D-хоррор от первого лица на **Three.js + Vite**.

Игрок исследует заброшенную квартиру, ищет выход, борется с галлюцинациями 
и теряющимся рассудком. Плёночные VHS-эффекты, система рассудка и заражения руки.

## 🎮 Управление
- **WASD** — движение
- **Мышь** — обзор
- **Shift** — бег
- **Ctrl** — присед
- **E** — взаимодействие
- **Esc** — пауза

## 🚀 Запуск
```bash
npm install
npm run dev
```
Открой http://localhost:5173

## 🛠 Стек
- Three.js r160
- Vite 5
- Web Audio API
- lil-gui (отладка)

## 📁 Структура
```
src/
├── core/        — FSM, игровой цикл, ввод, ядро, сохранения
├── player/      — камера, движение, руки, инвентарь
├── world/       — Apartment, Stairwell, Street, Trench, Forest
├── audio/       — звуковой менеджер
├── mechanics/   — рассудок, галлюцинации, сюжетные триггеры
├── fx/          — VHS, зерно плёнки, красная пульсация
└── ui/          — HUD, субтитры, меню, boot screen
```
